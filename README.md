# OSIP v2

## Orenz Industrial Intelligence & Procurement Platform

OSIP v2 is the canonical next-generation platform for
revenue-first industrial intelligence, spare-parts procurement,
and commercial operations.

## Status

Foundation Initialization

## Architecture

OSIP v2 follows a modular-monolith architecture with:

- React + TypeScript + Vite
- NestJS API
- PostgreSQL / Supabase
- Cloudflare infrastructure
- Audit and security layers

## Principles

- Evidence > Narrative
- Verified > Assumption
- Revenue > Efficiency > Convenience
- Free-First / Low-Cost
- Security by Design
- Preserve Before Modify
- Reuse Before Rebuild
- Do Not Automate Unproven Processes

## Repository

This repository is the canonical source repository for OSIP v2.

Legacy systems and previous artifacts are preserved separately
and are not automatically treated as production requirements.

## Current Phase

Foundation implementation.

Inventory implementation remains blocked until its
source-of-truth is verified.
